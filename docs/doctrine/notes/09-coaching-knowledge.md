## Invariants observed (doctrine candidates)

- **One gated neural seam**: model outputs reach coaching advice through exactly one adapter (JEPAInsightAdapter), triple-gated — setting flag, trained-weights load (26-HYB-01), head_trained sidecar marker (F-0029). Dead inference paths get deleted (F-0028), not left running.
- **Comments must tell the truth**: DA-03 renamed a module to admit it does arithmetic; F-0027 removed a phantom lock from a comment; F-0028 renamed "ML confidence" to baseline math. The codebase treats stale prose as a defect class.
- **Absent beats fabricated** (stated verbatim in pro_bridge): incompatible-scale metrics are omitted, not converted by guess; placeholder stat cards are skipped, not mined (CHAT-06).
- **Silence is a valid coaching action**: explainability <0.2 delta ⇒ no message; JEPA \|delta\|<0.1 ⇒ noise; semantically-void directions dropped. (Echoes RAP's confidence-gated silence — a cross-architecture principle.)
- **The coach's boldness scales with the model's maturity**: the MaturityObservatory state machine feeds the insight adapter's hedging/confidence/candidate-count ladder, and CoachTrainingManager's maturity multipliers scale confidence — introspection is wired into the product voice.
- **Learning from experience is bounded and auditable**: EMA-merged, trial-gated (≥5), context-matched feedback (WR-60), staleness-decayed, discarded-not-deleted, replay deterministic (DET-01).
- **Degradation is tiered and loudly tagged**: baseline C-41 three-tier ladder with age checks; degraded-baseline tag appended to user-visible messages; fallback embedder announces quality loss (H-01).
- **Ratio-vs-percent is a named defect class** (C-3/V-2/R4 ×3): every HLTV-derived percentage passes a defensive 1.0-boundary normalizer.
- Storage access exclusively via `get_db_manager()` — raw sqlite3 on a guessed path silently created empty DBs (R4, pro_demo_miner).
