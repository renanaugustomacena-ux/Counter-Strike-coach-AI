## Invariants observed (doctrine candidates)

- **Zero-trust at the LLM boundary** (DP-03/BE-03): everything the model supplies is validated against DB-known values; everything the model is shown from attacker-influenceable stores is sanitized. The LLM is treated as an untrusted co-processor on both channels.
- **Anti-hallucination is enforced structurally, not just by prompt**: VERIFIED-DATA blocks, suppressed placeholder stats, "n/a" over fake zeros, match-inventory injection, disambiguation-instead-of-guessing, tutor-mode 2nd→3rd person rewrite. The prompt rules (WR-78/79) are the last layer, not the only one.
- **Degradation is a ladder with named quality levels**, and the user is told which level they got (P9-03 mode labels). Every rung guarantees non-zero output (C-01).
- **Timeout budgets are hardware-reasoned and documented in place** (CHAT-01's Gemma latency analysis; stream stall vs whole-response budgets separated by F2).
- **Failure telemetry must itself fail loudly** (26-ORCH-01); failure counters reset per unit of work (O-01); repeated failures escalate to the user.
- Tick-rate resolution in services follows the same SSOT ladder as processing (column → MatchMetadata → canonical WARN) — 26-NORM-01 reaches the service layer.
