## (A) DECISION SHEET

### A1. Tick rate / time unit
- Chosen: 64 Hz, 1 tick = 15.625 ms; P = round(tick_rate/8) so the token stays 125 ms on 128-Hz servers (P1 §7.3, 26-NORM-01).
- Evidence T1 (`T1_tick_rate`): slope of time_in_round vs tick in 173 rounds: median 64.0, p05 64.0, p95 71.39 (rounds with timer reset) (P2 §12.2).

### A2. Token length
- Chosen: P = 8 ticks = 125 ms, `Conv1d(31 → 128, kernel=8, stride=8)` — a learned linear combination of all 8 ticks, no decimation (P2 §10.5, P1 §7.3/§7.4, P3 §4.1 `patch_ticks=8`).
- Alternatives considered: 1 tick (production; degenerate), HEPA P=16, LeNEPA P=25 on 5000 samples.
- Evidence: identity R² at 8 ticks = 0.97418 (still 97 % identity — the token itself is not the prediction horizon; the horizons are, see A10) vs 0.99776 at 1 tick; mean |Δ| per component 5.8e-3 at 8 ticks vs 7.9e-4 at 1 tick (P2 §12.2 T2). Rule stated in P2 §1.4: minimum useful horizon = where R²_id drops below ~0.9 → 32 ticks.

### A5. Batch size
- Chosen: B = 128 windows → input (128, 48, 31), latents (128, 48, 128); 20 000 steps ≈ 2.56 M window draws (P1 §7.3/§7.5, P3 §4.1 `batch_size=128`). Legacy comparison A is also run at B = 128 ("con B = 1 la ricetta attuale non è nemmeno definita", P1 §7.5).
- Evidence: VICReg variance estimator CV = √(2/(n−1)) = 1.41 (n = 2), 1.00 (n = 3, RAP `_fetch_rap_windows` window_size 96 / seq_len 32), 0.25 (n = 33), 0.14 (n = 101) (P2 §2.3.1, App. A.4); production B = 1 makes VICReg inert by construction (`jepa_model.py:440-441` returns 0 for shape[0] < 2). SIGReg minibatch bias O(1/n), irrelevant from n = 16 (Thm 6); measured `theorem6_bias.per_N`: bias of unscaled loss = c0/N = 0.0658 (N = 16), 0.0329 (32), 0.0219 (48), 0.0164 (64), 0.0110 (96), 0.0082 (128), 0.0053 (200), 0.0041 (256), 0.0021 (512), matching measured means within MC error (|z| ≤ 2.7). Published: LeJEPA stable from B = 128; LeWM B = 128; LeNEPA B = 256 (P1 App. A.2). P2 §2.3.3: B ≥ 32. P1 §3.6: covariance d×d has rank ≤ N−1 (with d = 256, N = 128 singular — fine as regularizer, not as estimate).
- Data supply: 2 497 non-overlapping 384-tick windows per M ticks → ≈ 1.1 M for ~442 M DB ticks (≈ 0.37 M for the 147.5 M figure; see B5), so 2.56 M draws = 2–7 passes over non-overlapping positions (random offsets make effective diversity higher).

### A8. Projector and where SIGReg/loss are computed

### A9. Predictor form
- 2 causal Transformer blocks over z_{≤t}, conditioned on horizon h ∈ {1, 4, 16} via FiLM (γ_h ⊙ z + β_h, learned embedding per horizon; reuse of `FiLMLinear` from `nn/layers/superposition.py`) → ẑ_{t+h} → h_ψ (P1 §7.4, P2 §10.7, P3 §4.1 `predictor_layers=2`). ### A11. Loss and weights

### A12. SIGReg: statistic, directions, target distribution, sample-size behaviour
- Statistic: Epps–Pulley exactly as `lucas-maes/le-wm module.py`: M = 1024 unit Gaussian directions (columns normalized) resampled every step with seed = global_step (P3 §4.6 uses `seed·1_000_003 + step`), 17 trapezoid knots on [0, 3] (weights 2Δt interior, Δt at ends, × window e^{−t²/2}; integrand symmetric so only [0, 3] is integrated), x_t = (ZA) ⊗ t, error per knot (mean cos x_t − e^{−t²/2})² + (mean sin x_t)², statistic = N·Σ_k w_k err_k averaged over M (P2 §2.3.2, App. A.5; P3 §4.1 `sigreg_num_proj=1024, sigreg_knots=17, sigreg_t_max=3.0`). LeJEPA: 17 knots, domain [−5, 5], M = 1024 (512 competitive, 16 works when resampled), hyperparameters negligible impact (Tab. 1a); resampled directions accumulate linearly with time (Fig. 7) (P2 §2.3.2).
- Target distribution: N(0, I) isotropic Gaussian on the projector output (64-d). Justification: unique minimizer of worst-case linear-probe bias/variance (LeJEPA Lemma 1–2: anisotropy amplifies ridge bias λ/(λ₁+λ) > λ/(λ̄+λ) and OLS variance Σ 1/λ_j by Jensen) and of integrated k-NN / Nadaraya–Watson bias via Fisher information J(p) ≥ tr(Σ⁻¹) with equality iff Gaussian, and tr(Σ⁻¹) minimal for equal eigenvalues under trace/det/Frobenius/spectral constraints (Thm 7–9) (P2 §4). VICReg constrains only two moments (Thm 3: K+2 points give distinct distributions with equal first K moments; LeJEPA Fig. 6 "X" distribution) (P2 §2.3.2). CDF tests rejected (sorting, ℓ∞, instability) (P2 §2.3.2).
- Application: temporal (the T tokens of ONE window are the sample; LeNEPA eq. 2) at taps, weight 2.5, plus batch (the B windows at each t; LeWM Alg. 3 `SIGReg(emb.transpose(0,1))`) at weight 0.1; both needed because batch-only SIGReg leaves the time axis free → emergent temporal straightening S_straight = mean cos(v_t, v_{t+1}), v_t = z_{t+1} − z_t (LeWM App. H), benign for planning but a risk for a coach that must see peeks/flicks (P2 §2.3.3, §6.3); S_straight must be logged (P3 §4.9). HEPA applies SIGReg on the predictor output (P2 §2.3.3).
- Gradient bounds: |∂EP/∂z_i| ≤ 4/(N s²), |∂²EP/∂z_i²| ≤ C√π/(2N s³), ‖∇_θ EP‖ ≤ (4s²/N)Σ_i‖aᵀ∇_θ f_θ(x_i)‖ — uniformly bounded for any embedding distribution (Thm 4); bias O(1/n) (Thm 6); M = O(K) directions suffice for Sobolev-smooth densities (Thm 5) (P2 §2.3.2).
- Scale (T7, `T7_sigreg`, n = 4096, D = 256, M = 1024): isotropic Gaussian 1.054; archived embeddings 660.6; standardized per coordinate 76.3; random net 2 026; collapsed (constant + 1e-3 noise) 4 237 (P2 §12.6). ### A18. Horizon-conditioned event heads (HEPA)
- Form: frozen encoder; predictor + linear head finetuned (HEPA 198 k params vs 2.16 M end-to-end vs 513 linear probe); hazard λ_Δt(t) = σ(wᵀĥ_{(t,t+Δt]} + b) (eq. 3); p(t, Δt) = 1 − Π_{j≤Δt}(1 − λ_j(t)) (eq. 4, monotone non-decreasing by construction); loss Σ_{Δt=1..K} w₊·BCE(p(t,Δt), y(t,Δt)), w₊ = N_neg/N_pos (eq. 5); BCE on the cumulative CDF smooths across horizons but distorts the probability scale → recalibrate per horizon (P2 §8.3, §9.3, App. O). ### A23. Architecture-level rules carried from P2 §10
